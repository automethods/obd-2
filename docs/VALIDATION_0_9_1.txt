WHAT WAS EXERCISED

- All 42 sensor definitions identify analogue, digital, pulse, discrete or
  derived behavior. Six exact sample-rate groups match the actual sensor bank.
- Solved coolant-divider voltage is distinguished from illustrative analogue
  transfers. The brake switch's 0/5 V states and pulse-to-speed conversions
  agree with runtime values. Calculated channels expose no wire voltage or
  independent connector claim.
- Grouping is a view operation. Sensor IDs, connector banks, cavity numbers,
  selected objects and running model state remain unchanged. Changing RPM
  changes pulse frequency, not sampling-group membership.
- One central ECU/BMU housing is retained with surrounding sensor nodes.
  New characteristics fit within the node and connector geometry bounds.
- Direct Disconnect/Reconnect callbacks reach the shared connection API.
  Invalid readings remain invalid rather than becoming a fabricated zero.
- Regular and reproducibly irregular sensor-contact schedules use only the
  2 ms simulation clock. Pause and read-only operations do not advance them.
- Intermittent MAF loss gives missing measured input, the model's 70 percent
  torque allowance, pending/stored P0102, signal recovery and 100 percent
  allowance after recovery. Stored memory remains until cleared.
- Crank loss inhibits engine operation. BMU pack-input loss removes torque
  permission and records the declared module event. The coolant open circuit
  retains its actual high input voltage and P0118 behavior.
- Brief dropouts can occur between samples or fail the diagnostic debounce.
  No forced diagnostic code or instantaneous recovery sample is invented.
- Transition events, history, regular boundaries and irregular phase sequences
  are invariant under different advance-call partitions. Multiple sensors
  have independent reproducible schedules.
- Invalid settings are atomic. Direct connection commands and Stop & reconnect
  cancel the selected schedule. Code clearing leaves a running test active.
- The actual application test clicks Start intermittent and Stop & reconnect,
  follows the real HTTP response into the schematic, and freezes its countdown
  while paused. Explicit sensor selection keeps the same fault-control target
  when another sensor disconnects or recovers.
- Saved-log deadlines remain anchored after an off-grid command. Actual final
  snapshots can be recorded; the logger does not invent interpolated values.

LIMITS

No native browser layout/input, GPU rendering or particular Linux Mint install
was verified for this release. No browser-launch restriction was bypassed.
The parsed-node and CPU checks do not establish those platform behaviors.
The 34 local checks are for the user's observations, not a pre-filled pass record.

Sensor ranges, timing and fault responses are declared teaching assumptions.
BMU coverage is pack voltage/current/temperature plus calculated SOC, not a
full cell-monitor harness. Most electrical transfers and pulse previews are
illustrative. Intermittent contact loss is not a vibration/corrosion/noise model.
Older PDFs remain theory references with earlier UI screenshots.

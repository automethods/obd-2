Wheel angles advance with simulated time, remain fixed while time is unchanged,

VERIFICATION LIMITS
This workspace cannot launch Chromium because the sandbox blocks its profile
socket. The separate cloud browser cannot reach the workspace loopback server.
Therefore full browser interaction/pixel verification and WebGL2 GPU rendering
are not claimed. The existing jsdom suites remain optional development checks;
jsdom was not available for this recovery run. Historical UI validation in
UI_VALIDATION.json belongs to the supplied v0.3 baseline, not this new build.
The user's Linux Mint installation and a physical shared/noexec mount were not
tested. Runtime requirements remain Python 3.10+ and a modern web browser.

SCOPE
This is a deterministic generic teaching model, not OEM firmware, an
instruction-set emulator, a real vehicle interface or a HIL environment.
CAN probes are data/freshness observations, not electrical bit waveforms.
The bundled renderer is WebGL2/Canvas; Three.js itself is not bundled.
A documented adapter and sample GLB are provided. Import support is the
rigid, uncompressed subset documented in VEHICLE_MODELS.md.

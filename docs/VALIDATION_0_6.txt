PACKAGING
The standalone is built with tools/build_standalone.py. The final artifact is
validated separately with tests/check_download.py, which starts the actual

LIMITS OF THESE CHECKS
The parsed-node harness runs the actual application callbacks but is not a
browser. Native layout, pointer/tab behavior, browser accessibility trees,
WebGL GPU output and the user's Linux Mint installation remain unverified.
The earlier restricted browser launch was not bypassed or retried. Use the
18 checks in the current workspace guide on the target computer.

DESIGN REVIEW
The layout was reviewed for fixed application controls, panel scrolling,
small center panes, wrapping component labels and consistent state/selection.
The 3D scene is a linked component locator, not a second simulation engine.

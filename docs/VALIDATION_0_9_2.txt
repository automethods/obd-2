WHAT WAS VERIFIED

- Actual UI -> serialized Session -> loopback HTTP -> VehicleSim. The command
  queue still permits at most one concurrent mutation.
- Petrol, diesel and BEV remain stationary with drive gear, accelerator and
  parking brake applied. Explicit release preserves the gear and allows motion.
  Reverse and manual gearbox warning conditions are exercised too.
- Prominent parking tell-tales, a direct release button and current-gear advice
  reflect actual state. No automatic parking-brake release was added.
- Driver seat belt and driver door have strict boolean model controls, shared
  snapshot/history/export state and changed-state-only BODY events. They do not
  advance simulation time, invent emissions codes or add propulsion locks.
- Lamps are illuminated only with ignition on. Reset restores a fastened driver
  belt, closed driver door and applied parking brake.
- Body controls remain usable during WLTC without overriding its virtual driver.
- Full and compact RPM gauges start their red zone at the configured engine
  redline. Diesel uses its own scale; BEV has a motor-power gauge without an
  engine-RPM band. SVG visibility uses actual style/attributes.
- The compact dashboard stays visible with scan tool, guided faults, unit map,
  signals, wiring, locations and fitted-configuration summary. It is outside
  the independently scrolling tools and uses no separate timer or simulation.
- Ignition, automatic/manual assisted engine start or READY, stop, parking-brake
  release and driver checks work while the service tools remain visible.
- A crank sensor failure changes real engine state, warning lamp and compact
  readings while the scan tool stays open. View changes preserve time and faults.
- Full driver controls uses the same vehicle. Editing a new vehicle hides the
  operating dashboard; cancelling returns to the same paused vehicle.
- Start availability observes model interlocks. Inhibited engines are described
  as inhibited instead of being told to start. Local notices clear on recovery.
- Existing momentary pedals, keyboard release, sensor characteristics,
  intermittent faults, diagnostics and recorded-log timing passed regression.

LIMITS

Native browser layout/input, WebGL GPU rendering and the user's particular
Linux Mint installation remain unverified. The browser launch restriction was
not bypassed. The 40 local checks are for the user's observations.
Only the driver seat-belt buckle and driver door switch are represented here;
there is no complete passenger-occupancy, restraint or four-door body model.
Warning and driving responses are generic simulator assumptions. CAN remains
a diagnostic lesson transcript, not a physical CAN-error/arbitration model.
Earlier PDF books remain theory references with earlier UI screenshots.

Verification boundaries
This task's execution sandbox does not permit binding local HTTP sockets. The new test transport invokes the production HTTP handlers with in-memory streams; it does not replace scanner, vehicle, sensor or cycle logic. Native browser checks use saved outputs from these same model/handler classes for layout and native interactions, not a claim of an end-to-end running localhost server. Native-browser physical response is covered by the actual-model interaction contract test, rather than by the snapshot-based layout checks.
The older application/Canvas integration suites require an unavailable @napi-rs/canvas dependency and localhost sockets, so they were not rerun here. Their scanner-tab expectations were updated for the new default and four tabs. Physical OBD hardware and certified WLTP testing are outside this simulator's scope.

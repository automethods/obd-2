REFERENCE & HELP

Using the workspace

Choose a vehicle, then choose your workspace

Start with 1 · Vehicle. Choose a car and open Customize vehicle & test conditions for transmission, chassis, sensors, cabin equipment, road conditions and the driving task. Draft edits take effect only when you press Continue → choose workspace.

  1. 2 · Workspace offers Drive and Diagnostics & service. Select either; both use the vehicle you just prepared.
  2. In Drive, turn ignition on, then press Start engine or Enable READY. Apply the foot brake, select D, release the parking brake and use the accelerator. The vehicle responds continuously; no separate Run command is needed. D or R requires the engine running or READY. Stop the vehicle and press Start WLTC to let the virtual driver prepare and drive it.
  3. Diagnostics & service → Diagnostics contains the scan tool and guided faults. Use Switch ignition on to power the units, match the CAN bitrate and connect. The compact vehicle dashboard stays visible above the tools. Start or stop the engine there; the gauges and warning lamps follow the same vehicle while you diagnose.
  4. Diagnostics & service → Vehicle units contains the unit map, grouped signals, wiring, connectors and component locations. Selecting an object keeps the same vehicle context.
  5. Vehicle configuration shows the fitted hardware. Edit vehicle & test conditions opens the same global vehicle editor.

Switching Drive and service keeps the clock, faults and recordings. Change vehicle pauses the run and releases the controls. Cancel changes resumes the same vehicle; applying changed settings creates a new parked vehicle and clears the current run. Export it first if you want to keep it.

Record every 0.1 s, 1 s or 1 minute of simulation time and export values with validity as CSV. No hardware adapter is required.

Dashboard and driver checks

ODO and Trip A follow actual distance traveled. Set a starting odometer in vehicle setup; Reset Trip A clears only the trip. New vehicle/Reset starts from the configured baseline.

A red circled P means the parking brake is applied. In a drive gear, the cluster offers Release parking brake beside the warning. Driver checks let you fasten/unfasten the seat belt and open/close the driver door; red lamps follow those states while ignition is on. These are warnings, without an automatic propulsion lock. RPM gauges have a red zone beginning at the configured engine redline; the electric vehicle uses a power gauge.

In service, a compact dashboard remains above the scrolling tools, including live RPM/power, speed, gear and warning lamps. You can switch ignition on, start/stop, release the parking brake and change driver checks here. Use the small momentary pedals or W / ↑ and S / ↓ while inspecting the tools. Gear selection offers brake/clutch assistance. Press a pedal or choose Drive manually to take over from WLTC; the vehicle keeps responding. Full driver controls opens the larger cockpit.

Sensor types, timing and live faults

In Vehicle units, use Group by in Unit map or Arrangement in Wiring & connectors to organize sensors by type or sample rate. Expand Characteristics to see analogue voltage, digital states, pulse conversion, range and sampling. A pulse frequency changes with motion; sampling cadence and CAN bitrate are separate.

Use a sensor’s Disconnect/Reconnect control during the run. Select the sensor in the schematic for Start intermittent: set connected and dropout times, with regular or reproducibly irregular timing. The countdown uses simulation time. Stop & reconnect cancels the fault injection. Short interruptions may recover before a diagnostic code is confirmed; stored codes remain after signal recovery. Derived values have no independent unplug control.

OBD, CAN and the socket

OBD / UDSThe diagnostic question and answer. For example, “What is the engine speed?”
ISO-TPPackages that question into CAN frames; splits longer replies into several frames.
CANThe vehicle message network. This lab creates frame bytes in memory.
DLC socketThe physical access point. CAN-H is pin 6, CAN-L pin 14; power is pin 16, grounds are pins 4 and 5.

The coolant electrical divider is solved. Other sensor outputs are generic teaching approximations with stated sample periods. CAN voltage levels and bit timing are explanatory references.

What can run?

The compact scanner opens with the selected unit’s main live parameters. Use Numbers or Graphs and + Add parameter to customize the readings. Fault codes applies to the selected unit; Vehicle scan lists all fitted units. Messages/Events stay collapsed until you open them; Expand trace is optional.

OBD current data, pending/stored emissions codes, code clearing and VIN; a small UDS session/identification subset. Other fitted units expose clearly labelled simulated state, without invented OEM diagnostic addresses.

J1850, ISO 9141-2, KWP2000, DoIP and LIN are reference topics. There is no real adapter connection or OEM firmware in this package.

Keyboard

1 Drive · 2 Diagnostics & service (after vehicle setup) · W / ↑ Accelerator · S / ↓ Brake · A / D or ← / → Steering · C Clutch · Esc Close a drawer. Hold driving keys to apply controls; release to release pedals and centre keyboard steering. Driving keys are inactive while typing or in Help. During WLTC, pressing a pedal or W/S takes manual control; steering is available after takeover. Focused sliders retain their native arrow keys.
